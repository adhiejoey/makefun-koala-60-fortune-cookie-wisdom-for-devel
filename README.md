A single original fortune-cookie line for a software developer, written in the voice of a tired senior engineer: the code you will one day inherit was written by a stranger who shares your name and none of your memory — a quiet warning about legacy code, undocumented decisions, and the future self who has to live with them. Running `node main.ts` writes that one line to `entry.txt` in the output directory.
